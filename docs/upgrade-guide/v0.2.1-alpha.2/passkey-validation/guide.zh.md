# 通行密钥响应校验

[English](guide.md) | 中文

## 变更

通行密钥注册允许省略 `credProps` 和 `rk` 扩展输出。注册和认证拒绝跨来源客户端数据及任何 `topOrigin` 字段；本部署仅支持同源流程。注册拒绝解码后超过 1023 字节的凭据 ID。现有凭据存储和用户句柄的格式保持不变。

## 迁移

1. 部署更新后的服务端，重新开始注册或认证流程；不要重放旧挑战的响应。
2. 在配置的公开来源上，以顶层页面打开安全页面。不支持跨来源嵌入式认证。
3. 使用你的认证器确认注册和随后的通行密钥登录。如果认证器返回超长凭据 ID，请使用其他认证器或密码登录。不要删除或重新初始化认证数据库。
