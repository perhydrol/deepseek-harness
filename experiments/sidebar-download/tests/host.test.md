English | [中文](host.test.zh.md)

[host.test.js](host.test.js) invokes the HTTP handler with in-memory request and response objects. Each fixture owns its registered route and cleanup function. The workspace-move regression retains an original session header while the file service resolves a different root, and checks both listing and byte reads against that resolved scope. Authentication rejection must leave scope resolution untouched. The [Host entry](../src/index.md) owns the behavior these cases exercise.
